# History Layer Lab · 图层讲解引擎

可直接离线打开的通用叠层讲解工具。本仓库只含原创代码和虚构界面测试样例，不含具体时代地图或地图数据。没有自动下载真实地理数据，也不自动启用 GitHub Pages。

## 运行

用现代浏览器打开 `dist/index.html`，不需要账号、密钥、依赖安装或联网。点击“加下一层”、独立开关、点选对象聚焦和“全图”，观察同一画布中不同信息如何累积。可下载观察 JSON。

## 接入口播

在页面选择本机音频和动作轴 JSON，文件留在浏览器本机，不上传。音频的 `currentTime` 是唯一同步时钟。格式：

```json
{"cues":[{"start":0,"end":4,"step":0},{"start":4,"end":8,"step":1}]}
```

时间单位为秒，区间左闭右开；必须有序、不重叠，step 为 0 到步骤数减一。区间空隙保留当前状态；手动操作会暂停播放，重播恢复同步。错误动作轴会清除之前的轴，避免继续使用过期信息。没有默认音色、配音服务调用或所需密钥；本包不含豆包、Edge 或其他声音素材。

## 代码结构

- `dist/model.js`：纯状态模型、动作轴验证、跳转与序列化；支持浏览器及 Node。
- `dist/renderer.js`：图层显隐、对象焦点、本机音频和交互适配器。
- `dist/scenario.js`：虚构对象、分层步骤配置。x/y 仅为画布像素单位，不是经纬度。
- `dist/index.html`：原创抽象形状样例，不代表真实地理。
- `tests/model.test.js`：零第三方依赖测试，执行 `node tests/model.test.js`。

接入具体历史专题时，需要自行准备有权使用的地理数据，明确每层年代、精度、来源与未决问题，并按实际发布地和内容处理地图审核。代码的 MIT 许可不能替第三方地图、配音、字体、现代译注或图片授权，也不代表实际地图可免审公开。

## 验证与未覆盖

模型测试覆盖独立图层、跳转、输入拒收、动作轴边界、正反向时间跳转和错误替换清理。云端浏览器已检查可见图层、点选聚焦、关层保留底层、错误轴反馈与合成计时音驱动。合成测试音不作为发布素材。此包不承诺真实手机或中国运营商网络验收，也不包含任何配音质量评价。
